Anlass melden

Vereine, Gemeinde, Kirche, Schule und Gewerbe können ihre Anlässe hier über ein einfaches Formular melden. Der Verkehrsverein prüft jede Meldung, bevor sie im Kalender erscheint.

Das Formular wird bald freigeschaltet.

So kommt der Dorfkalender aufs iPhone

  1. In Safari unten rechts auf ••• tippen, dann auf «Teilen».
    Ältere iPhones: unten direkt auf den Teilen-Knopf □↑ tippen.

  2. Auf «Mehr anzeigen» tippen (oder nach unten wischen).

  3. Auf «Zum Home-Bildschirm» tippen.

  4. Oben rechts auf «Hinzufügen» tippen. Fertig – das Kalender-Symbol ist jetzt auf dem Startbildschirm.
